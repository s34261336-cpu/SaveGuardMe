# SaveMod

Telegram-бот для отслеживания изменений и удалений сообщений в личных чатах
подключённого Telegram Business-аккаунта. Работает на Python и aiogram 3.x.

## Запуск за 3 шага

### 1. Добавьте Secrets

В **Tools → Secrets** добавьте:

| Имя | Значение |
| --- | --- |
| `BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |

Не вставляйте токен в `main.py` и не отправляйте его в чат.

### 2. Запустите бота

Нажмите **Run**, откройте бота в Telegram и отправьте `/start`. Любой пользователь
может запустить бота и подключить собственный Business-аккаунт.

### 3. Подключите Telegram Business

В настройках Telegram откройте **Settings → Automatization** и подключите бота
к Business-аккаунту. После подключения бот пришлёт `✅ Бот подключён`.

## Размещение на BotHost / Bothost

В корне уже есть `main.py` и `requirements.txt`, подходящие для Python-бота:

1. Импортируйте репозиторий или архив проекта в BotHost.
2. Укажите точку входа `main.py` (если хостинг не определил её автоматически).
3. Добавьте секрет `BOT_TOKEN` в настройках бота и запустите деплой.

Подробнее: [настройка главного файла в Bothost](https://bothost.ru/docs/main-file-entrypoint.md).

`OWNER_ID` больше не нужен: уведомления идут в приватный чат конкретного
пользователя, который сам подключил свой Business-аккаунт. Запускайте только один
экземпляр бота с этим токеном: перед стартом на BotHost остановите polling в Replit,
иначе процессы будут конфликтовать.

## Что отслеживается

- Редактирование текста и подписей к медиа.
- Удаление текста, фото, видео, голосовых сообщений, документов, стикеров,
  аудио и видеосообщений.
- В уведомлениях об изменении и удалении показывается автор исходного сообщения.
- Только личные чаты в Business-подключениях, которые пользователи подключили сами.
- Медиафайлы не скачиваются; в RAM сохраняются тип, текст, подпись и данные
  автора, необходимые для уведомления.
- В уведомлениях показываются ID сообщения и кликабельный профиль автора.

Telegram не передаёт боту имя человека, который нажал «Изменить» или «Удалить»,
поэтому уведомление показывает автора исходного сообщения.

Для личных чатов Telegram Bot API не предоставляет ссылку непосредственно на
сообщение; ID и ссылка на профиль помогают быстро найти нужный диалог.
Одноразовые/исчезающие медиа бот не сохраняет.

Кэш и ID Business-подключения хранятся только в RAM. Они очищаются при
перезапуске; сообщения, пришедшие до запуска или после потери кэша, могут быть
отмечены как `содержимое неизвестно`.
